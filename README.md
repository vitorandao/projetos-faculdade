## Sobre o repositório

Este repositório reúne **atividades, exercícios e trabalhos práticos** desenvolvidos ao longo do curso de **Engenharia de Software** no **Centro Universitário do Distrito Federal (UDF)**, organizados por disciplina e linguagem de programação.

O objetivo é manter um **histórico centralizado** de tudo que já foi produzido em sala de aula ou como exercício, servindo tanto como **portfólio de evolução** quanto como **material de consulta** para revisões futuras.

<br/>



>  Cada pasta contém subpastas nomeadas por **disciplina** e/ou **data da atividade**, facilitando a navegação e o histórico de evolução.
